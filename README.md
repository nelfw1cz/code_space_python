# PyEdit 🐍

Простой, легковесный и функциональный редактор кода для Python, написанный на встроенной библиотеке **Tkinter**. Этот проект создавался как рабочий прототип (MVP) для тестирования логики быстрых шаблонов кода, встроенного запуска и файлового менеджера.

## ✨ Ключевые фичи
* 📂 **Проводник файлов (File Tree):** Отображает структуру текущей папки, позволяет открывать `.py` файлы двойным кликом.
* ⚡ **Панель быстрой вставки (Code Templates):** Вставка циклов (`for`, `while`), условий (`if/else`), функций (`def`) и конструкций ровно в позицию курсора.
* 🎨 **Подсветка синтаксиса:** Базовая подсветка ключевых слов Python для улучшения читаемости.
* 🖨️ **Встроенная консоль:** Запуск текущего скрипта в один клик с перехватом вывода (`stdout`) и ошибок (`stderr`) прямо в окне редактора.
* ↩️ **Умные автоотступы:** Автоматический перенос отступов и добавление 4 пробелов, если предыдущая строка заканчивалась на `:`.

## 🛠️ Технологический стек
* **Язык:** Python 3.x
* **GUI Фреймворк:** Tkinter / TTK
* **Системные модули:** `subprocess`, `sys`, `os`

## 🚀 Как запустить
Для работы редактора не требуются сторонние библиотеки, нужен только установленный Python 3.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку и запустите скрипт:
   ```bash
   python main.py
   ```
